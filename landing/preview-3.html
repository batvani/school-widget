Install in 2 minutes.

You need an iPhone and the free app Scriptable.

1

Get Scriptable

Free in the App Store. Open it once.

2

Add the Shortcut

“School Widget Installer” opens in Shortcuts. Tap Add Shortcut.

3

Run it

It downloads School Widget and opens it. Tap Allow the first time.

The Shortcut doesn't work?

Copy the installer script into Scriptable, or paste the code by hand.

Questions

Is it free?

Yes. School Widget and Scriptable are both free.

What does it send, and where?

Nothing. It only downloads updates and the holiday list from GitHub.

The widget doesn't change

iOS refreshes widgets when it decides. Hold the widget, Edit Widget, pick the script again.

Can I use it in Bulgarian?

Yes, Bulgarian is the default. English is one setting.
